QoF v1.6.0's "Unleashed" Update

A Minecraft Bedrock addon that adds small vanilla-friendly features. Each module is configurable through the in-game pack settings panel.note

Base Game Version: 26.52
Dependency: 2.10.0

Changelog

  • QoF no longer blocks Achievement Progression. You can now install QoF in a normal survival world and earn achievements alongside your friends.
  • Migrated to @stable APIs, moving away from experimental dependencies.
  • Updated solid block detection to work correctly under the stable API.
  • The wiki has been refreshed with the latest changes. Explore it at qof.aitji.xyz.
  • Removed the beta API checker from mcfunction.
  • Removed the Minecraft addon version display from /info and /qof:info.

Offhand

  • The offhand visual helper now responds with instant sounds and particles instead of on-screen notification messages, keeping things snappier and less intrusive.
  • Items with lock mode set will no longer be moved into the offhand slot.

v1.5.1 Take me there

1.5.1

  • All major updates are now named.
  • Some frequently used player data is now cached: name, platform type, gamemode, and permission level.
  • Permission level is no longer ignored. Players now need at least member permission to interact with QoF.
  • New command: /info
    • Shows the current QoF version.
    • Shows which modules are enabled.
    • Useful for bug reports.
  • Removed some settings considered "too advanced".
If you still want to edit removed configs, check ~/behaviors_pack/QoF/scripts/_config.js.

Bartering Bat

This module is managed by @pickerth_12 and cannot be disabled because it does not live in scripts.

  • Hold a glow berry to lure a bat.
  • Feed a bat with a glow berry to trade.
  • 2-minute cooldown per trade.
